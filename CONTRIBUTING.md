# Contributing to CatchShield AI

Thank you for your interest in CatchShield AI! This project is a prototype built for the CodeGyaan'26 ChainCraft track.

## Code of Conduct

Please treat all contributors with respect. We foster a collaborative, inclusive environment.

## How to Contribute

1. **Fork the Repository**
2. **Create a Feature Branch:** `git checkout -b feature/your-feature-name`
3. **Run Tests:** Ensure all backend and frontend tests pass.
    ```bash
    # Backend tests
    cd backend
    pytest
    ```
4. **Commit Your Changes:** `git commit -m 'Add some feature'`
5. **Push to the Branch:** `git push origin feature/your-feature-name`
6. **Open a Pull Request**

## Development Areas

We welcome contributions in the following areas:
- **ML Integration:** Replacing the heuristic environmental screening with a trained AI model.
- **Web3 Integration:** Wiring the FastAPI backend to interact with the provided Solidity smart contracts.
- **Mobile PWA:** Enhancing the offline capabilities and sync strategies for mobile devices at remote landing centers.
